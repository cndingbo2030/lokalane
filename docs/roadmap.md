# Roadmap

## Milestone 0: Foundation

- Brand, repository, architecture and MVP map shell.
- Free provider strategy.
- OneMap proxy boundary.
- Initial CI checks.

## Milestone 1: Singapore Alpha

- OneMap live search through edge proxy.
- LTA parking availability feed.
- LTA bus arrival feed.
- POI detail quality model.
- Basic user correction form.

## Milestone 2: Cross-Border Beta

- Woodlands and Tuas route dashboards.
- JB POI and parking layer.
- Causeway report workflow.
- Offline SG/JB map package research.

## Milestone 3: Monetization Pilot

- AdMob native ad experiment.
- Sponsored POI admin workflow.
- Merchant landing and claim process.
- Frequency caps and ad quality controls.

## Milestone 4: Native App

- Capacitor or React Native shell decision.
- Push notifications for saved commutes.
- Background location permission strategy.
- App Store and Google Play compliance review.
